# Send a selection

1. Select some lines of code.
2. Run **Notival: Capture selection** from the Command Palette (⇧⌘P), or right-click the selection and choose it.
3. Notival opens with a new note containing your code, its language and the file and line numbers.

Keep selections under about 70 KB (a few hundred lines).

## From the sidebar

Open the **Notival** icon in the activity bar. *This file* lists your functions and classes. The copy button copies a function's code; the arrow sends it to Notival. *Sent to Notival* is a list of everything you have sent, so you can find your way back to it.
