# Notival + VS Code

**Notival** is a notebook for understanding: notes, code you can run, equations, flashcards and study tools in one place.

This extension connects it to your editor:

```
VS Code  ──  select code  ──▶  a note in Notival
VS Code  ◀──  click the link  ──  the note's block
```

Nothing is uploaded anywhere. Everything stays on your Mac. The extension only talks to the Notival app installed on this computer.

You need the Notival app installed and open at least once.
