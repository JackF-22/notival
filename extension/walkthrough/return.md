# Back to the source

- In Notival, a captured block shows where it came from. Click its source link and VS Code opens that file with the lines highlighted.
- Use **Comment in VS Code** on a block to leave your note as an inline comment on those lines. It lives in VS Code's comments panel and never changes your source file.

If the file has changed since you captured it, Notival asks you to capture the selection again rather than pointing at the wrong lines.
